Часті питання

My Planet поєднує ефективність для щоденного прибирання з уважним ставленням до родини, поверхонь і довкілля.

Так, засоби підходять для щоденного дому за умови використання згідно з інструкцією на упаковці.

Вони підходять для більшості твердих поверхонь: підлоги, кухонних поверхонь, ванної кімнати та інших зон дому.

Так, формули розраховані на регулярне використання для підтримання чистоти без зайвого навантаження.

Ні, продукти мають приємні аромати без відчуття агресивної хімії після прибирання.

Орієнтуйтеся на зону використання: кухня, прання, дитячі речі, скло або універсальний догляд для дому.
